# John Esguerra Biochemistry E-Portfolio

This is a lightweight static website. It has no build step and no external dependencies.

## Publish with GitHub and Cloudflare Pages

1. Upload every file and the `assets` folder to the root of a GitHub repository.
2. In Cloudflare, open **Workers & Pages**, then create a **Pages** project.
3. Connect the GitHub repository.
4. Choose **None** for the framework preset.
5. Leave the build command blank.
6. Set the build output directory to `/`.
7. Deploy the project.

Future GitHub commits will trigger a fresh Cloudflare Pages deployment automatically.
